🩹 修复语义

补丁、臂、判词、转正——修东西的黑话全解，附刚出炉的 v10 判词。

一次修复的完整生命周期

发现症状 → 定位病灶 → 写补丁（默认关）→ bench 加臂 → 同种子 A/B → 出判词 → 转正或放弃

关键词解释：

  • 补丁：一小段改动文件。平时关着，主代码逐位不变；带 token 跑才生效
  • 臂：bench 里的一个参赛版本。一次改一个变量，才知道分数变化归谁
  • 判词：测试后的官方结论，写进 docs/，判死不翻案
  • 转正：补丁合入主线（走 0005 式流程）
  • 留观：有微弱信号，记下来下次再测

为什么"方向错了还有提升"

提升有两种：止损型（填坑，方向无关）和 开疆型（找到更好的走法，方向有关）。

之前的提升全是止损型：悬崖双重收费每次罚 1149 分，修掉它任何方向都涨。v10 判词证明：在现在这套看得见的项目里，开疆型的旋钮没有了（四个臂零变化）。

手写 7 万路线图：缺的是功能，不是调参（2026-09-13 定）

锚点事实：人类玩家能打到 7 万。这证明上限不在游戏机制——同一把牌人能打出 7 万，我们打 6.4 万，差距通常不是"旋钮不够细"，而是"人看得见的一些东西，我们的评分层看不见或不会表示"。

路线 = 扩可见面：把人打牌时盯的东西列成清单，逐项对照评分层，缺一项补一项：

  • 训练等级门槛（几级训练才值得点）
  • 体力红线与休息时机（不是休息定价，是何时必须休）
  • 支援卡羁绊触发时机（绊满前该站哪格）
  • 事件窗口（连续事件链的取舍）
  • 失败率管理（高风险训练的期望值）
  • PT 换分效率（点数花在哪最值）
  • 粉丝数——按实测前提划掉（每个马娘有必打目标赛，粉丝数可能不用管，待实测确认）

纪律：每补一项做成新特征+新 token，默认关，同种子进 bench 配对验——用防骗三规管着，不许拿单世界线的运气当结论。

证据链（2026-09-13 打捞完成）：38 仓 5645 个历史 CI run 全扫——均分从未到过 72000/76000；历史最高均分是神经网络 EXP-014 的 70495.9（4200 局配对）；72000/76000 是单局分的密集区间（最高 79187）。"人能达到 7 万+"在单局意义上完全成立。EXP-014 配置已还原：模拟器锁的正是暮雪流年仓库里的版本，补丁链、训练参数、种子全部可复现——数据不再"拿不到"。

均分轨迹一句话：手写 65438 → 手写冠军 65554 → 首个神经网络 65669 → 学生纪录 66735 → MCTS 教师 68407 → nn014 三种子 70335～70496（首次破 7 万）。手写与最好成绩差约 5000 分，差距来源被 v10 判词定位：缺的是评分层看不见的项目，不是旋钮没拧——正好接住上面的路线图。
