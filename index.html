⚠️ 三条必须记住的教训

  1. 上传文件必须提交进分支。泳装青云天空的 2798 个原始抓包文件只传了 blob 没提交，被 GitHub 回收，永久丢失。教训记在「修 Bug 语义」。
  2. 不同口径的分数不能互相比。64271（REC 直跑）、66734.8（EXP-009b 冠军）、72000/76000（神经网络迭代、数据在暮雪流年的电脑）是三把不同的尺子。
  3. 冠军必须换种子复验。EXP-009 把同时期最优结论落地、砍掉不良结论，等于在不同世界线之间挑樱桃——那个"最优"可能只是运气。详见「PR 语义」。
